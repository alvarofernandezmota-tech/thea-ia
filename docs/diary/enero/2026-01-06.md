### ⚠️ Desafíos Encontrados
1. **Case-sensitivity en Git (Windows)**
   - Problema: Archivos con MAYÚSCULAS vs minúsculas
   - Solución: `git config core.ignorecase true`
   - Impacto: Mínimo, resuelto fácilmente

2. **Terminal PSReadLine (Visual)**
   - Problema: Errores de renderizado ocasionales
   - Solución: No afectó funcionalidad
   - Impacto: Cosmético, ignorable

3. **Carpeta .archive gitignored**
   - Problema: `.archive/README.md` no se commiteó por gitignore
   - Solución: Agregar vía `git add -f` si es necesario
   - Impacto: Menor, ya documentada localmente

### 💡 Lecciones Aprendidas
1. Workflow incremental = mejor historial y debugging
2. Conflictos case-sensitivity comunes en repos multi-plataforma
3. Stashear cambios no relacionados > force merges
4. 5 commits pequeños > 1 commit grande = mejor review
