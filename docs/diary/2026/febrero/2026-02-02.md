## ✅ Trabajo realizado

### 1. Resolución error WSL `0x80370102`
- Contexto: al intentar instalar una distro con `wsl --install` aparecía el error `WslRegisterDistribution failed with error: 0x80370102`.
- Análisis: el servicio WSL2 y las características de Windows estaban correctas, así que el problema era la virtualización por hardware desactivada.
- Acciones:
  - Verificar que `Virtual Machine Platform` y `Subsistema de Windows para Linux` estaban activados en “Características de Windows”.
  - Ejecutar `wsl --status` y confirmar que la versión por defecto era WSL2.
  - Confirmar que no había distros correctamente instaladas todavía (`wsl -l -v`).

### 2. Activar virtualización en BIOS/UEFI
- Entrar en la BIOS/UEFI del equipo desde el arranque.
- Localizar y activar opciones de virtualización (Intel VT-x / AMD-V / SVM / “Virtualization Technology” según la placa).
- Guardar cambios y reiniciar Windows.
- Verificar en el Administrador de tareas → pestaña “Rendimiento” → CPU que aparecía `Virtualización: Habilitada`.

### 3. Instalar WSL2 + Ubuntu 22.04
- Fijar WSL2 como versión por defecto:

  ```powershell
  wsl --set-default-version 2
  ```

- Instalar Ubuntu 22.04 LTS:

  ```powershell
  wsl --install -d Ubuntu-22.04
  ```

- Primer arranque de Ubuntu dentro de WSL2:
  - Crear usuario UNIX:

    ```text
    Enter new UNIX username: alvaro
    New password: ********
    ```

  - Confirmar prompt correcto para trabajar siempre aquí:

    ```text
    alvaro@Alvaro:~$
    ```

  - Decisión explícita: todo el trabajo de THEA IA (Python, Postgres, tests, etc.) se hará **siempre** en este prompt de Ubuntu, dejando PowerShell solo para comandos de gestión de WSL.

### 4. Actualización completa de Ubuntu
- Ejecutar en el prompt `alvaro@Alvaro:~$`:

  ```bash
  sudo apt update && sudo apt upgrade -y
  ```

- Se actualizan paquetes base (git, curl, python3.10, systemd, snapd, etc.), dejando el sistema listo para:

  - Instalar Python 3.11 y PostgreSQL.
  - Clonar el repo `thea-ia` y crear el entorno virtual dentro de Ubuntu.
