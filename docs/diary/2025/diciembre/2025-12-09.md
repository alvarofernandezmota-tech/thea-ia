def cleanup_old_snapshots(self, keep=10):
if len(self.snapshots) > self.max_snapshots:
sorted_snapshots = sorted(
self.snapshots.values(),
key=lambda x: x.timestamp
)
for snapshot in sorted_snapshots[:-keep]:
del self.snapshots[snapshot.snapshot_id]

## 🎯 DECISIONES TÉCNICAS DEL DÍA

### **Decisión #1: Deep Copy en Context Isolation**
CRÍTICO para evitar mutaciones accidentales
context = deepcopy(initial_data) # ✅
context = initial_data # ❌ NO HACER

Justificación: En sistemas multi-tenant,
compartir referencias causa bugs silenciosos
text

### **Decisión #2: SHA256 Checksums**
Para verificar integridad de snapshots
checksum = hashlib.sha256(
json.dumps(data, sort_keys=True).encode()
).hexdigest()

Justificación: Detectar corrupción de datos
en recovery scenarios
text

### **Decisión #3: Scope Isolation Strategy**
3 niveles de scope, no más
LOCAL: Máximo aislamiento
SHARED: Herencia controlada
GLOBAL: Datos públicos

Justificación: Balance entre flexibilidad
y complejidad mantenible
